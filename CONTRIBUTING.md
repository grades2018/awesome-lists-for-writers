# Contributing

Thanks for helping improve this list.

- One list per pull request, added to the section where it fits best.
- Only curated lists (awesome lists, reading lists, directories) that help people write, edit, publish, or market books. Single tools belong in the topic lists linked here.
- The list should be maintained, or clearly marked as not updated recently.
- Format: `- [List Name](https://github.com/owner/repo) - Short description.`
- Please explain in the pull request what the list covers and why it helps writers.
- No affiliate or tracking links.
